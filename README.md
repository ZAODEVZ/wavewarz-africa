## How this office works

| Folder | What goes in it |
|---|---|
| [`log/`](log/) | One file per month. A dated line for every battle, decision, post or call. Newest first. |
| [`plans/`](plans/) | One file per plan, such as the money split or the Tuesday Respect game. Same header every time: State, Owner, Next. |
| [`notes/`](notes/) | Everything else worth keeping: research, ideas, people, links. |

- IMan's side writes and pushes straight to `main`. Zaal's side comments on an issue or opens a PR.
- This repo is **public**. Never put the following here: wallet seeds or keys, private messages, money owed between people, phone numbers, or anything personal. Link to where it lives instead.
- Decisions made in a DM or on a call get one line in `log/` the same day.
